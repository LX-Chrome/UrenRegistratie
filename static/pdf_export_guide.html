PDF Export Setup Guide

Problem: PDF export functionality requires wkhtmltopdf to be installed on your system.

Installing wkhtmltopdf

Windows

  1. Download the installer from wkhtmltopdf.org
  2. Choose the Windows installer for your system (64-bit recommended)
  3. Run the installer and follow the instructions
  4. By default, it will install to C:\Program Files\wkhtmltopdf
  5. Restart your application after installation

macOS

Using Homebrew:

brew install wkhtmltopdf

Linux (Ubuntu/Debian)

sudo apt-get update
sudo apt-get install wkhtmltopdf

Linux (CentOS/RHEL)

sudo yum install wkhtmltopdf

Testing Your Installation

After installation, you can verify it's working by running:

wkhtmltopdf --version

Common Issues

  • Path not found: Ensure wkhtmltopdf is in your system PATH
  • Missing dependencies: Some Linux distributions might need additional packages
  • Permission issues: Ensure the application has permission to execute wkhtmltopdf

Alternative: Use other export formats

If you can't install wkhtmltopdf, you can still use Excel or CSV exports which don't require additional software.
