## About Time Registrator

Time Registrator is a comprehensive web-based time tracking and project management application built with Flask. It allows users to:

- Track working hours with detailed time entries
- Perform real-time check-ins to monitor work status
- Manage clients and their information
- Track projects and assignments
- Maintain employee records
- Generate comprehensive reports in various formats
